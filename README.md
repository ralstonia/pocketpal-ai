# Video Pal speech demonstration

A continuous 14-second iPhone 16e screen recording, cropped from the user-provided original, with original AAC app audio retained. Ordinary tabletop objects are used.

[Watch the demo](video-pal-demo.mp4)

The recording shows the earlier working camera-to-description-to-speech feature. Final PR revision b09eb80 was separately installed on the iPhone and its speech and camera-stop behavior confirmed by the tester. This clip does not demonstrate stopping the camera. Header and fallback safeguards added during PR preparation have automated coverage.

Only this selected excerpt is published. This evidence branch is separate from the upstream feature branch.
